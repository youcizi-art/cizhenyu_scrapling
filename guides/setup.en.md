# Scrapling setup

1. This repo is a CIZHENYU Deploy protocol wrapper around the official PyPI package `scrapling[ai]`.
2. In Toolbox → Add tool, use: `https://github.com/youcizi-art/cizhenyu_scrapling` (or a local ZIP).
3. Install creates `.venv` and runs `pip install scrapling[ai]`.
4. Enable the tool to use Scrapling MCP in your Agent.
